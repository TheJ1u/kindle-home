# Kindle Home

A simple browser homescreen for a Kindle e-reader, hosted on GitHub Pages.

- **index.html** — paper version (black on white). Best for the Kindle's e-ink screen.
- **night.html** — starfield version with shooting stars. Best viewed on a color screen (phone/computer); e-ink won't animate it.

## Use it on a Kindle
Open the Kindle's Web Browser and go to the Pages URL, then bookmark it or set it as the browser home.
